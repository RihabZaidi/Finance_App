A simple personal finance tracker web application built using HTML, CSS, and JavaScript. This app allows users to add income and expense entries, view their total balance, and track their financial activities.

🚀 Features
📥 Add income and expense transactions

📃 View transaction history

💵 See total balance, total income, and total expenses

🗑️ Remove transactions

💾 Data saved locally using localStorage

🛠️ Technologies Used
HTML — for structuring the app layout

CSS — for styling and UI design

JavaScript — for application logic and dynamic interactions

LocalStorage — for saving data in the browser

📌 Future Improvements
Add user authentication

Connect to a backend and database

Add monthly/yearly financial reports

Add charts and analytics
